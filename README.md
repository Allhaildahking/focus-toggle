# Focus Toggle

A tiny, distraction-free focus mode built with plain HTML, CSS, and JavaScript.

## What it does

Focus Toggle lets you switch a page between normal mode and a minimal focus mode. Your preference is saved in the browser, so it stays active after a refresh.

## Features

- Simple focus mode toggle
- Smooth visual transition
- Remembers your setting with `localStorage`
- Responsive layout
- No frameworks
- No APIs
- No backend
- No external dependencies

## Built with

- HTML
- CSS
- JavaScript

## Run locally

Clone the repository and open `index.html` in your browser.

That's it. No installation required.
